# NEON WALLET — Telegram Mini App starter

## Что реализовано
- Мобильный интерфейс в тёмно-зелёном неоновом стиле.
- Telegram WebApp SDK, серверная проверка подписи `initData` и срока `auth_date`.
- Автоматическое создание пользователя при первом входе, далее восстановление профиля из SQLite.
- Баланс RUB/USDT, кнопки пополнения/вывода/наличных, список заявок.
- Все операции сейчас **демо-заявки**: не принимают и не переводят реальные деньги, балансы не изменяются.

## Запуск
1. Установите Node.js 20+.
2. Скопируйте `.env.example` в `.env`, вставьте токен бота из BotFather в `BOT_TOKEN`.
3. В терминале в папке проекта:
   ```bash
   npm install
   npm start
   ```
4. Для Telegram нужен публичный HTTPS адрес. Для локального теста используйте туннель HTTPS (например, ngrok) и задайте URL Mini App в настройках бота через BotFather.
5. Откройте приложение из меню/кнопки Telegram-бота.

## Важно
- Не публикуйте BOT_TOKEN и не добавляйте его во frontend.
- Для реальных финансовых операций необходимы легальный платёжный провайдер, KYC/AML где применимо, безопасная админ-панель, аудит и юридическая проверка. Не храните карточные данные самостоятельно.
